# src/

This directory contains the `workspace_os` Python package.

- `workspace_os/` — the package source code (CLI, state, mission, validator, etc.)
- `workspace_os.egg-info/` — auto-generated by setuptools (git-ignored; do not commit)
- `workspace_os.egg-info/PKG-INFO` — setuptools-generated metadata; recreated on every `pip install -e .`
- `workspace_os/__pycache__/` — Python bytecode cache (git-ignored)

For package architecture and entry points, see `../README.md` and `../runbook.md`.
